# Lớp học TikTok LIVE – Bản thử nghiệm trên iPhone

Mã game ở file [index.html](./index.html). Bản chơi gồm cô giáo hoạt hình, bàn giáo viên, bàn ghế học sinh, bảng câu hỏi, 143 câu hỏi thuộc Lịch sử – Văn học – Khoa học – Địa lý, đếm giờ, tính điểm, tự chuyển câu, thêm câu hỏi.

## Cách mở trên iPhone (GitHub Pages)

1. Vào **Settings → Pages** của repository này.
2. Trong **Build and deployment**, chọn **Deploy from a branch**.
3. Branch: **main**, Folder: **/(root)**, rồi bấm **Save**.
4. Khi xuất bản xong, mở địa chỉ GitHub Pages hiện trong phần Pages và dùng Safari.

**Lưu ý:** Tên repository hiện tại có dấu chấm ở cuối: `classroom-tiktok-live.`. Đường dẫn chơi phụ thuộc vào tên repository thực tế.

## Quà TikTok LIVE

Nút giả lập tặng quà chỉ để thử hiệu ứng: **chưa tự động nhận quà thật từ TikTok LIVE**. Để nhận sự kiện quà thật phải có một kết nối máy chủ riêng. File HTML này không yêu cầu quyền truy cập tài khoản TikTok.

## Dữ liệu câu hỏi

Câu hỏi thêm từ giao diện được lưu bằng `localStorage` trên thiết bị/trình duyệt hiện tại. Xóa dữ liệu Safari có thể làm mất các câu đã thêm.

Dự án được tối ưu cho màn hình iPhone, không cần cài đặt ứng dụng.
